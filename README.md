# Contabilità Familiare

Prima versione Flutter dell'app di contabilità familiare.

## Funzioni
- Dashboard mensile
- Inserimento entrate e spese
- Categorie
- Storico movimenti
- Resoconto mensile
- Grafico entrate/spese
- Salvataggio locale con SharedPreferences
- Eliminazione movimenti
- Selezione mese
- Budget mensile per categoria (struttura pronta)

## Avvio
```bash
flutter pub get
flutter run
```

Per APK:
```bash
flutter build apk --release
```
