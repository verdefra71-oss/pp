# Certificazioni Elettriche v5

Versione aggiornata con PDF strutturato in stile **D.M. 37/2008 / Allegato I**:
- dati impresa, CCIAA/REA, responsabile tecnico;
- committente, proprietario, ubicazione e destinazione d'uso;
- descrizione impianto e intervento;
- avviso preliminare sulla possibile necessità di progetto;
- norme tecniche applicate;
- relazione materiali e verifiche;
- checklist allegati;
- tabella tipologia prodotti/componenti;
- spazi firma e consegna;
- archivio locale delle certificazioni.

## Importante
Il PDF è un **modello digitale di compilazione**, non una dichiarazione ufficiale precompilata dallo Stato. Prima dell'uso professionale deve essere verificato dal soggetto abilitato rispetto al modello ministeriale vigente, al D.M. 37/2008 e alle norme CEI/UNI applicabili al caso concreto.
